ر# SafeLend: Predicting Loan Default with Machine Learning 🏦📊

SafeLend is a Machine Learning project designed to predict credit risk and loan default probability. It helps financial institutions evaluate applicant risk using data-driven classification models.

## 📁 Repository Structure
- `project.ipynb`: Data exploration, pre-processing, feature engineering, and model training.
- `app.py` / `3.py`: Application interface / script.
- `requirements.txt`: Python dependencies required to run the project.

## 🛠️ Tech Stack
- **Python**
- **Pandas, NumPy, Scikit-learn, Keras/TensorFlow**
- **Streamlit** (for web deployment)
